# 2026-08-21

## link-nvidia Dockerfile 全面修复

### 根因
- `tar -zxf` 未指定 `-C /tmp/`，解压到 CWD(`/`)，但后续 `mv` 命令在 `/tmp/` 中查找 → amd64 构建失败
- amd64 tar 包含扁平 `sing-box` 文件；arm64 tar 包含 `sing-box-<ver>-linux-arm64/` 目录（含 sing-box + libcronet.so）
- arm64 的 `libcronet.so` 未被复制到镜像中，是 glibc 链接的，在 Alpine (musl) 上需要 `gcompat`

### 修复清单
1. **Dockerfile**: 添加 `-C /tmp/` 到 tar 解压命令；合并 4 个 RUN 为 1 个层；安装 `gcompat`；处理 arm64 libcronet.so；修复 shell `|| true` 优先级掩盖 mv 失败的 bug（用 `{ }` 分组）；合并 mkdir 到 entrypoint COPY 层；HEALTHCHECK start-period 5s→10s
2. **entrypoint.sh**: 二进制调用改绝对路径（/usr/sbin/rsyslogd2、/usr/local/bin/php-fpm、/usr/local/bin/subscriptiond）；移除死代码 SING_BOX_VERSION/CLOUDFLARED_VERSION；WARP 密钥默认值无条件设置（避免 WARP 禁用时 config 模板产生空值导致 sing-box 崩溃）
3. **docker-compose.yml**: 移除废弃 `version: '3.8'`；WARP_ENABLED 默认值 true→false（与 entrypoint 一致）
4. **config.yaml.template**: `reserved` 字段去掉引号（`${WARP_RESERVED}` → 生成数组而非字符串）
5. **GitHub Actions main.yml**: 移除未使用的 build-args（SING_BOX_VERSION/CLOUDFLARED_VERSION）和对应 env 变量（Dockerfile 无 ARG 声明，被静默忽略）

## 运行时第二处报错修复

### 报错
`decode config at /etc/apache2/config.json: dns.servers[0].address: json: unknown field "address"`

### 根因
sing-box 1.12+ 的 `type: "https"` DNS server 已无 `address` 字段（该字段属于已废弃的 legacy 格式，需 ENABLE_DEPRECATED_LEGACY_DNS_SERVERS 才生效）。config.yaml.template 中 google/alidns 两个 DoH 服务器误用了 `address`，严格 JSON 解析直接报错。

### 修复
- templates/config.yaml.template: 删除 google 和 alidns 两个 HTTPS DNS server 的 `"address": "..."` 字段（server 已包含服务器地址，地址多余且非法）
- 注意：`server` 使用域名 dns.google / dns.alidns.com，依赖 `detour: "direct"` 的 dialer 解析；若运行时 DoH 解析失败，可改为 IP+`tls.server_name` 模式（如 server: 8.8.8.8 + tls.server_name: dns.google）

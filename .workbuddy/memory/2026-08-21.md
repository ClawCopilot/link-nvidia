## link-nvidia Dockerfile 全面修复

### 根因
- `tar -zxf` 未指定 `-C /tmp/`，解压到 CWD(`/`)，但后续 `mv` 命令在 `/tmp/` 中查找 → amd64 构建失败
- amd64 tar 包含扁平 `sing-box` 文件；arm64 tar 包含 `sing-box-<ver>-linux-arm64/` 目录（含 sing-box + libcronet.so）
- arm64 的 `libcronet.so` 未被复制到镜像中，是 glibc 链接的，在 Alpine (musl) 上需要 `gcompat`

### 修复清单
1. **Dockerfile**: 添加 `-C /tmp/` 到 tar 解压命令；合并 4 个 RUN 为 1 个层；安装 `gcompat`；处理 arm64 libcronet.so；修复 shell `|| true` 优先级掩盖 mv 失败的 bug（用 `{ }` 分组）；合并 mkdir 到 entrypoint COPY 层；HEALTHCHECK start-period 5s→10s
2. **entrypoint.sh**: 二进制调用改绝对路径（/usr/sbin/rsyslogd2、/usr/local/bin/php-fpm、/usr/local/bin/subscriptiond）；移除死代码 SING_BOX_VERSION/CLOUDFLARED_VERSION；WARP 密钥默认值无条件设置（避免 WARP 禁用时 config 模板产生空值导致 sing-box 崩溃）
3. **docker-compose.yml**: 移除废弃 `version: '3.8'`；WARP_ENABLED 默认值 true→false（与 entrypoint 一致）
4. **config.yaml.template**: `reserved` 字段去掉引号（`${WARP_RESERVED}` → 生成数组而非字符串）
5. **GitHub Actions main.yml**: 移除未使用的 build-args（SING_BOX_VERSION/CLOUDFLARED_VERSION）和对应 env 变量（Dockerfile 无 ARG 声明，被静默忽略）

- **README.md**: 在「内置组件版本」提示块补充说明 1.12+ 移除 geosite、改用 rule-set 实现分流。

### 关键事实（新增）

## 第六个坑：envsubst 只替换 exported 变量，entrypoint 未 export 模板变量

### 报错
`create service: initialize inbound[3]: missing uuid for user 0`（inbound[3] = TUIC `tuic-in`）

### 根因
- entrypoint.sh 用 `: "${UUID:=默认值}"` 等给模板变量设默认值，但**只 export 了 REALITY_* 和 WARP_*（旧第37-38行）**，UUID / REALITY_SNI / ARGO_DOMAIN 都未 export。
- `envsubst` 只读**环境（exported）变量**；未 export 的 shell 变量对它等于未定义 → 替换为空串。
- 关键证据：日志里 `UUID: 1b4db7eb-4057-5ddf-91e0-36dec72071f5` 正是 entrypoint 第7行的默认值，说明容器没在 environment 传 UUID，走默认值路径 → 该默认值未被 export → `${UUID}` 在 config.json 里变成 `""` → TUIC 因 `users.uuid` 为 Required 报 missing uuid。
- 为什么只有 TUIC 崩：VLESS/VMess 在 init 阶段不严格校验 uuid 空值，TUIC 会，故它成为第一个暴露空 uuid 的 inbound。
- 注：Dockerfile 已装 gettext（envsubst 存在），不是缺包问题。

### 修复
- entrypoint.sh：新增 `export UUID REALITY_SNI` 和 `export ARGO_DOMAIN`（与既有 REALITY_*/WARP_* 合并导出）。
- 将 `envsubst` 调用从 export 段（旧第39行）**下移**到 ARGO_DOMAIN 解析之后（auto-detect trycloudflare 域名之后），确保 vmess `server_name` 能拿到自动探测的 ARGO_DOMAIN。
- 校验：模拟 UUID 已 export 后渲染，TUIC inbound[3].users[0].uuid 正确填充为真实值，全部 inbound 用户字段非空——通过。

### 关键事实
- 这是前几轮审核漏掉的 envsubst 变量作用域陷阱：凡 `:="${VAR:=...}"` 设默认值、且模板用到 `${VAR}` 的，必须 export，否则走默认值路径时渲染为空。
